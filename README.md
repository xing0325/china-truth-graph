# 活在真实中 · Living in Truth

一份关于中国近现代民间记忆的可视化知识图谱：从被禁的书、被遮蔽的人与被改写的事件出发，沿着人物、著作、概念、平台和历史事件之间的关系继续阅读。

**在线浏览：** <https://xing0325.github.io/china-truth-graph/>

## 图谱内容

当前版本包含约 166 个节点和 300 多条关系，主要分为：

- 历史学者与研究者
- 海外汉学家与党史研究者
- 异见者、作家与记者
- 禁书、回忆录与历史著作
- 被遮蔽的历史事件
- 关键政治与社会概念
- 出版、传播和保存这些内容的平台

点击节点可以查看人物或作品简介及关联线索；搜索和分类筛选用于缩小图谱范围，帮助读者从一个已知名字进入更大的关系网络。

## 数据结构

数据按主题拆分在 `data/` 中，最后由 `99-assemble.js` 组装：

```text
data/01-historians.js          历史学者
data/02-sinologists-party.js   汉学家与党史研究
data/03-dissidents.js          异见者
data/04-writers.js             作家
data/05-journalists-foreign.js 记者与海外人物
data/06-books.js               著作
data/07-events.js              事件
data/08-concepts.js            概念
data/09-platforms.js           平台
data/10-edges.js               节点关系
```

新增内容时，请先确定稳定且唯一的节点 ID，再在对应主题文件加入节点，并在 `10-edges.js` 中添加关系。避免只添加孤立节点而不说明它与现有图谱的联系。

## 技术实现

项目使用原生 HTML、CSS 和 JavaScript，是一个无需构建步骤的静态站点。`graph.js` 负责图谱布局、交互、筛选与详情抽屉，所有数据均随页面静态加载。

## 本地预览

```bash
python -m http.server 4173
```

然后打开 <http://localhost:4173/>。
