# 活在真实中 · Living in Truth

一份给被洗脑教育所塑造之年轻人的私人地图。

中国近现代禁书、异见者、被遮蔽事件的可视化知识图谱。

166 个节点（89 位人物 / 30 部著作 / 20 个事件 / 15 个核心概念 / 12 个出版平台）与 307 条关系。

## 探索方式

- 点击节点打开词条，并只突出它的一度关系
- 搜索人名、书名、事件或概念，使用方向键与回车快速定位
- 点击左下角分类可筛选图谱；滚轮或右下角按钮缩放、适屏
- 拖动画布平移，拖动单个节点可微调位置；按 `/` 聚焦搜索，按 `Esc` 返回全图

图谱使用 PIXI.js 渲染，并在首屏前完成确定性的分组布局。点击和拖动不会重新启动整张图的物理模拟。
